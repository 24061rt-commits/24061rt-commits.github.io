<h3>自己PR</h3>
<ul> 
   <li>初めまして。私、るーっていいます。えーっと……ごめんなさい！あんまりこーゆーの得意じゃなくて…えーっと…私は、オンラインの大学の1年生で、この大学で『クリエイターになる』っていう夢を叶えるために、日々たゆまぬ努力を尽くしています。社会に出るためには勉強が必要不可欠ということで、厳しい世界に耐えながら、毎日のように勉強を頑張っています。
そんな私ですが、実は私には大きな野望があります。それは、『お友達を無限人作って、みんなを笑顔にすること』！人見知りで、お友達をたくさん作るのにどれだけ苦労したことか…そのことを今、とても後悔しています。でも、社会に出ればきっとまた新しい友達もたくさんできる…そんな予感がします。
今は3Dモデリングツールで、たくさんの作品を作っています。最初はただの暇つぶしのつもりだったんだけど…</li>
</ul>
